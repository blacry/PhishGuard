# Spotting and avoiding malware links

## Warning signs

- Messages that pressure you with threats, urgent deadlines, unexpected prizes, or sudden account problems.
- A hostname that only contains a trusted brand name as part of a longer, unfamiliar domain.
- Shortened links that hide the destination.
- Unexpected attachments, download prompts, or requests to install software.
- Requests to sign in or provide personal information through an unsolicited message link.

These clues are reasons to pause and verify. One clue alone does not prove a link is malicious.

## Safer habits

- Open banking, email, shopping, and other important services using the official app, a saved bookmark, or an address you type yourself.
- Verify unexpected requests using a phone number or website you already know is official.
- Never share a password or one-time code with a message sender or caller.
- Do not run files from unexpected messages. Keep your operating system, browser, applications, and security software updated.
- Report suspicious messages with the email or messaging service's report feature, then delete them.
- If you ran a suspicious file or entered credentials, contact your IT/support team. Change affected credentials from a trusted device through the service's official site.

CISA recommends being cautious with unexpected links and attachments, checking links before opening them, reporting suspicious messages, and installing software updates promptly. See [CISA phishing tips](https://www.cisa.gov/sites/default/files/2024-09/Secure-Our-World-Phishing-Tip-Sheet.pdf) and [CISA software update tips](https://www.cisa.gov/sites/default/files/2024-09/Secure-Our-World-Software-Updates-Tip-Sheet.pdf).
